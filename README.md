# BloodOps

BloodOps는 헌혈자의 센터 검색·예약·전자문진부터 의료진과 관리자의 예약·혈액 재고 운영까지 연결하는 헌혈 운영 통합 플랫폼입니다. 헌혈이 완료되면 헌혈 기록과 포인트 적립으로 이어지며, 이용자는 마이페이지에서 내역을 확인할 수 있습니다.

[프로젝트 발표자료 (PDF)](docs/BloodOps-project.pdf)

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 헌혈센터 검색 | 자체 센터 데이터와 네이버 지도를 활용해 키워드 검색 결과와 지도 위치를 연동하고, 선택한 센터에서 예약을 시작합니다. |
| 헌혈 예약·문진 | 센터·날짜·헌혈 종류·시간을 선택하고 예약 정보를 최종 확인합니다. 센터 운영 시간과 장비 수용량을 고려해 예약 가능 시간을 표시하며, 예약 조회·변경·취소, 확정 알림, 전자문진을 지원합니다. |
| 혈액 보유현황·재고 | 크롤링으로 수집한 적혈구·성분채혈혈소판 보유현황을 시각화합니다. 의료진 대시보드에서는 센터의 혈액 팩 재고, 상태, 유효기간을 관리합니다. |
| 헌혈 기록·포인트샵 | 헌혈 기록과 증명서를 확인하고, 헌혈로 적립한 포인트로 상품을 교환합니다. 포인트 적립·사용, 상품 재고, 교환 내역을 관리합니다. |
| AI 안내 챗봇 | Gemini로 질문 의도를 분류해 센터 검색·예약과 혈액 보유현황 등 관련 기능으로 안내합니다. |
| 회원·권한 | 자체 로그인과 Google·Naver·Kakao 소셜 로그인을 지원하며, 일반 사용자(USER)·의료진(MEDICAL)·관리자(ADMIN)의 화면과 접근 권한을 구분합니다. |

## 기술 스택

| 영역 | 기술 |
| --- | --- |
| 프런트엔드 | React 19, React Router DOM 7, Vite 8, CSS, Apache ECharts / LiquidFill |
| 백엔드 | Java 25, Spring Boot 4.1, Spring MVC, Spring Data JPA, QueryDSL, Maven Wrapper |
| 인증·인가 | Spring Security, OAuth2 Client, 이메일·문자 인증 |
| 데이터 | MariaDB, H2(개발·테스트), Redis |
| 외부 연동 | Naver Maps API, 카카오 예약 메시지, Gemini API, Jsoup 크롤링 |

React SPA는 Spring Boot REST API를 사용하며, 회원·예약·헌혈·재고·포인트 데이터는 MariaDB에서 관리합니다. [프런트엔드 README](frontend/README.md)

## k6 부하 테스트

발표자료 24쪽에 기록된 공개 조회 부하 테스트 결과입니다.

| 지표 | 결과 |
| --- | ---: |
| 최대 가상 사용자 | 500 VU |
| 테스트 시간 | 6분 30초 |
| HTTP 요청 수 | 118,698건 |
| HTTP 요청 실패율 | 0% |
| 전체 응답 p95 | 1.74초 |

목표였던 p95 2초 미만, HTTP 요청 실패율 5% 미만을 모두 충족했습니다. 발표자료의 구간별 p95는 공개조회(500 VU) 1,740ms, 상세 공개조회 219ms, 혈액 보유현황 406ms였습니다.
